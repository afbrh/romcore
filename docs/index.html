Supported devices

"Supported" means the devices I build and tune RomCore for. Performance settings, the controller layout and the interface are all designed and tested on them first.

RomCore may run on other Android devices, but I don't test on them, so speed, controls and layout can vary and I can't promise fixes. More devices will be added as I get to test them.

  • AYN Thor

Install

  1. Download the file above on your Android device.
  2. Open it. If Android asks, allow installs from your browser.
  3. Open RomCore and grant "All files access" when it asks. It uses this to find your ROM and BIOS folders.

You bring your own games and BIOS files. RomCore does not include any.
