The Legend of Zelda: Echoes of Wisdom (Switch), v1.0.1: "4:3 Aspect Ratio" by RomCore (960x720 render size, 4:3 camera aspect, UI layout un-stretch + edge anchoring).
The game renders a 960x720 picture; Eden stretches it into its 16:9 picture and RomCore stretches the picture back up to the full screen height while this folder exists.
Only applies to the build id 09A15C8259828A41B91B036B12F0687973A4627A (the game's 1.0.1 update, which is what the XCI boots). Installed by RomCore (core-eden). Delete this folder to turn it off; RomCore will not put it back.
Works together with the "NoDOF" mod. Known: menus/inventory screens are laid out for the full 16:9 width, so they appear a little smaller (nothing is cropped); full-screen backdrops/videos are cover-cropped at the sides.
