Pokemon Brilliant Diamond - 4:3 Aspect Ratio (RomCore)
Version 1.3.0, main build id 94CEAE325C205C4B9D6F7235552F28FD (title 0100000011D90000).
Sets the game's resolution to 960x720 (nine immediates) so the 3D view keeps the original vertical view (central 4:3 of 16:9), and forces the uGUI CanvasScaler to match width so the 1280-wide menu layouts fit uncropped in a 1280x960 canvas. The host then stretches 4/3 vertically.
Based on the resolution sites of Fl4sh9174's public ultrawide mod.
Known issues: menus are authored 16:9 so they appear smaller with black bars above/below (nothing cropped); only new-game intro, bedroom, X menu and Bag were checked; Pokedex, town map, Poketch, PC box, battles, title screen not checked.
