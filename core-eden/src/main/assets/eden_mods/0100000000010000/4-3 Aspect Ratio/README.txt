Super Mario Odyssey (Switch): "4:3 Aspect Ratio" by M&M and theboy181, from "Additional Aspect Ratios" v1.01 by RagdollClash (gamebanana.com/mods/447876).
One .pchtxt per game version (1.0.0, 1.2.0, 1.3.0); each only applies to its own build id.
The game then renders for a 4:3 view; RomCore stretches Eden's picture to fill the screen while this folder exists.
Installed by RomCore (core-eden). Delete this folder to turn it off; RomCore will not put it back.
v1.3.0 also carries a RomCore HUD fit: the HUD layout space is made 1280x960 and widgets near the top/bottom are anchored to the real screen edges, so the HUD is not stretched by the picture stretch.
