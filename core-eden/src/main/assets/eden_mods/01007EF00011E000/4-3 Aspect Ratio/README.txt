The Legend of Zelda: Breath of the Wild (Switch), v1.6.0 (main NSO build id 8E9978D50BDD20B4C8395A106C27FFDE): "4:3 Aspect Ratio" by RomCore.
The game renders the 3D world with a 4:3 projection (same vertical field of view, i.e. the centre 4:3 of the normal 16:9 picture, nothing squeezed) and the HUD / menu headers / prompts are moved to the 4:3 screen edges.
Eden shows it in its 16:9 picture and RomCore stretches the picture 4/3 vertically to fill the 1280x960 panel while this folder exists.
Only applies to build id 8E9978D50BDD20B4C8395A106C27FFDE (version 1.6.0 with the update, which is what the XCI boots). Delete this folder to turn it off; RomCore will not put it back.
Known: blurred full-screen menu/dialog backdrops (pause menu, save list, "Load save data?") only cover a centred 4:3-ish box with black borders around it; the "Tips and Tricks" loading screen has a cream band at the top;
list spacing in the save-slot dialog is uneven. Gameplay, HUD, pause menu contents and title screen are fine.
